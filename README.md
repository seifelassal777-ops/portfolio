# Seif Elassal: portfolio

My life so far, told as a road trip with music. A living map follows the journey through eleven stops, from Egypt to now, with a different song and a different art style for each stretch of road. Recruiters can skip straight to the work from the start menu.

Work in progress.

## Branches

- `main` is the live site.
- `dev` is where new chapters are built and checked before they go live.

## Folders

- `docs/` notes and inspiration.
- `design/looks/` the first three style previews (A cartoon, B 3D night, C scrapbook). A and B were kept as starting points.
